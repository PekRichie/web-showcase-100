# Hitel- és Törlesztőkalkulátor

- **Kategória:** Natív HTML5/CSS3/JS – Eszközök & Kalkulátorok
- **Technológia:** Native
- **Fájlok:** `index.html` (önálló, build nélküli HTML5/CSS3/JS)

## Leírás
Annuitásos havi törlesztőrészlet, teljes visszafizetés és kamatteher számító.

## Futtatás
Nyisd meg az `index.html` fájlt böngészőben, vagy indíts helyi statikus szervert a repó gyökeréből:

```bash
python3 -m http.server 8000
```

Majd látogasd meg: `http://localhost:8000/02-native-tools-calculators/020-loan-calculator/`
