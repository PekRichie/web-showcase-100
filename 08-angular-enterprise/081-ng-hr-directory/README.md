# Angular HR Alkalmazott-nyilvántartó

- **Kategória:** Angular 18 Standalone – Vállalati Alkalmazások
- **Technológia:** Angular
- **Fájlok:** `src/app/app.component.ts` (Angular 18 Standalone + Signals), `package.json`, `index.html`

## Leírás
Standalone komponens részleg-szűrővel és dolgozói adatlapokkal.

## Futtatás
Nyisd meg az `index.html` fájlt böngészőben, vagy indíts helyi statikus szervert a repó gyökeréből:

```bash
python3 -m http.server 8000
```

Majd látogasd meg: `http://localhost:8000/08-angular-enterprise/081-ng-hr-directory/`
