# Szabadság-igénylő Rendszer

- **Kategória:** Angular 18 Standalone – Vállalati Alkalmazások
- **Technológia:** Angular
- **Fájlok:** `src/app/app.component.ts` (Angular 18 Standalone + Signals), `package.json`, `index.html`

## Leírás
Szabadságkeret-kalkulátor és vezetői jóváhagyási folyamat.

## Futtatás
Nyisd meg az `index.html` fájlt böngészőben, vagy indíts helyi statikus szervert a repó gyökeréből:

```bash
python3 -m http.server 8000
```

Majd látogasd meg: `http://localhost:8000/08-angular-enterprise/082-ng-leave-requests/`
