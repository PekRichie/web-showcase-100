# Memóriakártya Játék

- **Kategória:** Natív HTML5/CSS3/JS – Interaktív UI & Játékok
- **Technológia:** Native
- **Fájlok:** `index.html` (önálló, build nélküli HTML5/CSS3/JS)

## Leírás
4×4-es párosító játék lépésszámlálóval és időmérővel.

## Futtatás
Nyisd meg az `index.html` fájlt böngészőben, vagy indíts helyi statikus szervert a repó gyökeréből:

```bash
python3 -m http.server 8000
```

Majd látogasd meg: `http://localhost:8000/03-native-ui-interactive/023-memory-cards/`
