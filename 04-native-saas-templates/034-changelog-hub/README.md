# Termék Változásnapló (Changelog)

- **Kategória:** Natív HTML5/CSS3/JS – SaaS Sablonok
- **Technológia:** Native
- **Fájlok:** `index.html` (önálló, build nélküli HTML5/CSS3/JS)

## Leírás
Címkék (Új / Javítás / Teljesítmény) szerint szűrhető kiadási jegyzék.

## Futtatás
Nyisd meg az `index.html` fájlt böngészőben, vagy indíts helyi statikus szervert a repó gyökeréből:

```bash
python3 -m http.server 8000
```

Majd látogasd meg: `http://localhost:8000/04-native-saas-templates/034-changelog-hub/`
