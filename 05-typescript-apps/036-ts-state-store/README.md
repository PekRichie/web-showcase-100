# Típusbiztos Mini State Store

- **Kategória:** TypeScript – Típusbiztos SaaS & Webes Modulok
- **Technológia:** TypeScript
- **Fájlok:** `src/app.ts`, `tsconfig.json`, `index.html`

## Leírás
Generikus, feliratkozás-alapú állapotkezelő TypeScriptben (Redux-minta).

## Futtatás
Nyisd meg az `index.html` fájlt böngészőben, vagy indíts helyi statikus szervert a repó gyökeréből:

```bash
python3 -m http.server 8000
```

Majd látogasd meg: `http://localhost:8000/05-typescript-apps/036-ts-state-store/`
