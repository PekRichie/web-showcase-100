# A/B Teszt Szignifikancia Kalkulátor

- **Kategória:** TypeScript – Típusbiztos SaaS & Webes Modulok
- **Technológia:** TypeScript
- **Fájlok:** `src/app.ts`, `tsconfig.json`, `index.html`

## Leírás
Konverziós ráta összehasonlító és Z-score alapú kiértékelés.

## Futtatás
Nyisd meg az `index.html` fájlt böngészőben, vagy indíts helyi statikus szervert a repó gyökeréből:

```bash
python3 -m http.server 8000
```

Majd látogasd meg: `http://localhost:8000/05-typescript-apps/055-ts-ab-test-calc/`
