# SoundWave Fesztivál

- **Kategória:** Natív HTML5/CSS3/JS – Landing oldalak
- **Technológia:** Native
- **Fájlok:** `index.html` (önálló, build nélküli HTML5/CSS3/JS)

## Leírás
Nyári zenei fesztivál oldal fellépő-keresővel és napijegy-kalkulátorral.

## Futtatás
Nyisd meg az `index.html` fájlt böngészőben, vagy indíts helyi statikus szervert a repó gyökeréből:

```bash
python3 -m http.server 8000
```

Majd látogasd meg: `http://localhost:8000/01-native-landing-pages/008-soundwave-fest/`
