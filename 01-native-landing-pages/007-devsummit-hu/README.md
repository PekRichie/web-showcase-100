# DevSummit Hungary 2026

- **Kategória:** Natív HTML5/CSS3/JS – Landing oldalak
- **Technológia:** Native
- **Fájlok:** `index.html` (önálló, build nélküli HTML5/CSS3/JS)

## Leírás
Tech konferencia oldal előadó-kártyákkal és sávszűrős programtervvel.

## Futtatás
Nyisd meg az `index.html` fájlt böngészőben, vagy indíts helyi statikus szervert a repó gyökeréből:

```bash
python3 -m http.server 8000
```

Majd látogasd meg: `http://localhost:8000/01-native-landing-pages/007-devsummit-hu/`
