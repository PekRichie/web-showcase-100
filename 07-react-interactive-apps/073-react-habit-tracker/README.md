# Napi Szokáskövető (Habits)

- **Kategória:** React 18 – Interaktív Webalkalmazások
- **Technológia:** React
- **Fájlok:** `src/App.jsx`, `package.json`, `index.html` (élő React 18 előnézet)

## Leírás
7 napos pipa-rács és sorozat (streak) számláló.

## Futtatás
Nyisd meg az `index.html` fájlt böngészőben, vagy indíts helyi statikus szervert a repó gyökeréből:

```bash
python3 -m http.server 8000
```

Majd látogasd meg: `http://localhost:8000/07-react-interactive-apps/073-react-habit-tracker/`
