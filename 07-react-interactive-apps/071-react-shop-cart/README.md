# React Webshop & Kosár

- **Kategória:** React 18 – Interaktív Webalkalmazások
- **Technológia:** React
- **Fájlok:** `src/App.jsx`, `package.json`, `index.html` (élő React 18 előnézet)

## Leírás
Kategória-szűrős termékkatalógus, dinamikus kosár és kuponkód.

## Futtatás
Nyisd meg az `index.html` fájlt böngészőben, vagy indíts helyi statikus szervert a repó gyökeréből:

```bash
python3 -m http.server 8000
```

Majd látogasd meg: `http://localhost:8000/07-react-interactive-apps/071-react-shop-cart/`
