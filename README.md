# Web Showcase 100 — CuppaShot Frontend & SaaS UI Gyűjtemény ☕

**100 különböző, kategorizált, futtatható weboldal és webes kisalkalmazás** négy technológiai sávban:
- **Natív HTML5 / CSS3 / Vanilla JS:** 35 projekt (landing oldalak, kalkulátorok, interaktív UI, SaaS sablonok)
- **TypeScript 5 (Strict):** 20 projekt (típusbiztos SaaS modulok és eszközök)
- **React 18 (Hooks):** 25 projekt (SaaS dashboardok és interaktív webalkalmazások)
- **Angular 18 (Standalone + Signals):** 20 projekt (vállalati alkalmazások)

🌐 Portfólió: [cuppashot.hu](https://cuppashot.hu) · 👤 Készítette: **Pék Richárd**
