# AI Prompt Játszótér

- **Kategória:** React 18 – SaaS Dashboardok & Admin Felületek
- **Technológia:** React
- **Fájlok:** `src/App.jsx`, `package.json`, `index.html` (élő React 18 előnézet)

## Leírás
System/User prompt sablonok, változó-behelyettesítés és becsült token-szám.

## Futtatás
Nyisd meg az `index.html` fájlt böngészőben, vagy indíts helyi statikus szervert a repó gyökeréből:

```bash
python3 -m http.server 8000
```

Majd látogasd meg: `http://localhost:8000/06-react-saas-dashboards/060-react-prompt-lab/`
