# API Kulcs Kezelő Panel

- **Kategória:** React 18 – SaaS Dashboardok & Admin Felületek
- **Technológia:** React
- **Fájlok:** `src/App.jsx`, `package.json`, `index.html` (élő React 18 előnézet)

## Leírás
Kulcs-létrehozás, maszkolás, jogosultsági körök és visszavonás.

## Futtatás
Nyisd meg az `index.html` fájlt böngészőben, vagy indíts helyi statikus szervert a repó gyökeréből:

```bash
python3 -m http.server 8000
```

Majd látogasd meg: `http://localhost:8000/06-react-saas-dashboards/063-react-apikey-vault/`
