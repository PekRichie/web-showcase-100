# Ügyfélszolgálati Ticket Rendszer

- **Kategória:** React 18 – SaaS Dashboardok & Admin Felületek
- **Technológia:** React
- **Fájlok:** `src/App.jsx`, `package.json`, `index.html` (élő React 18 előnézet)

## Leírás
Státusz-váltás, prioritás-szűrés és új hibajegy rögzítés.

## Futtatás
Nyisd meg az `index.html` fájlt böngészőben, vagy indíts helyi statikus szervert a repó gyökeréből:

```bash
python3 -m http.server 8000
```

Majd látogasd meg: `http://localhost:8000/06-react-saas-dashboards/059-react-ticket-desk/`
